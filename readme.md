# Monitoramento de Materiais Hospitalares



## Objetivo

Controlar materiais hospitalares e identificar itens em falta.



## Funcionalidades

- Listar materiais

- Identificar itens com baixo estoque

- Adicionar novos materiais



## Tecnologias

- Python (Flask)

- HTML, CSS, JavaScript



## Execução

1. pip install flask

2. python backend/app.py

3. abrir index.html
